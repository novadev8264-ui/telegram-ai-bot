راهنمای نصب بازی موش و گربه PULSE
=================================

نام پوشه جدید بازی: pulse_cat_mouse

این بسته فقط شامل فایل‌های افزوده‌شونده است؛ فایل‌های قدیمی پروژه در آن وجود ندارند و قرار نیست جایگزین شوند.

ساختار فایل‌ها در ریشه مخزن GitHub باید این‌طور باشد:

PULSE/
  bot.py                         (قدیمی؛ دست‌نخورده)
  bot_cat_mouse.py               (جدید؛ فایل اجرای جداگانه)
  pulse_cat_mouse/               (پوشه جدید)
    __init__.py
    game.py
    map.py
    players.py
    movement.py
    turns.py
    rules.py
    display.py
  games/                         (قدیمی؛ دست‌نخورده)

نکته درباره GitHub موبایل:
برای ساخت پوشه، لازم نیست پوشه خالی بسازید. از Add file > Create new file استفاده کنید و نام مسیر را دقیقاً وارد کنید، مثلاً:

pulse_cat_mouse/__init__.py

سپس کد فایل مربوطه را در محتوای همان فایل قرار دهید و Commit کنید. برای هفت فایل دیگر نیز همین کار را با مسیرهای زیر تکرار کنید:

pulse_cat_mouse/game.py
pulse_cat_mouse/map.py
pulse_cat_mouse/players.py
pulse_cat_mouse/movement.py
pulse_cat_mouse/turns.py
pulse_cat_mouse/rules.py
pulse_cat_mouse/display.py

دو فایل زیر باید در ریشه مخزن باشند، نه داخل پوشه pulse_cat_mouse:

bot_cat_mouse.py
README_CAT_MOUSE_FA.txt

اجرای نسخه جدید:
پس از بارگذاری و بررسی فایل‌ها، در Railway فقط Start Command را به این مقدار تغییر دهید:

python bot_cat_mouse.py

این کار bot.py را ویرایش نمی‌کند؛ Railway به‌جای آن فایل اجرای جداگانه را اجرا می‌کند. bot_cat_mouse.py بازی‌های قبلی را نیز از پوشه games بارگذاری می‌کند.

دستورهای بازی در گروه:
/mousegame   ساخت بازی و ثبت‌نام
/mousemap    نمایش نقشه و وضعیت
/mousestatus نمایش بازیکنان و وضعیت بازی

بازیکنان باید پیش از شروع، در گفت‌وگوی خصوصی ربات /start را اجرا کنند تا ربات بتواند نقش و نوبتشان را خصوصی بفرستد.

نام بازیکن در فهرست قابل کلیک است: اگر username داشته باشد به t.me/username وصل می‌شود؛ در غیر این صورت از پیوند تلگرامی tg://user?id استفاده می‌شود.

محدودیت مهم:
وضعیت بازی در حافظه نگهداری می‌شود؛ با Restart یا Deploy مجدد Railway، بازی در حال اجرا از بین می‌رود. بازی باید پس از راه‌اندازی مجدد دوباره ساخته شود.

آزمایش:
فایل‌های پایتون از نظر Syntax بررسی شده‌اند. اجرای واقعی با توکن تلگرام و تست گروهی در این محیط انجام نشده است؛ قبل از استفاده عمومی، ابتدا در یک گروه آزمایشی بررسی کنید.
